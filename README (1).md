# SITI NURBAYA — Rematri

Aplikasi edukasi anemia remaja putri (skrining, kalender haid, pengingat, cadangan data).
Data disimpan di browser masing-masing (localStorage). Tidak ada server.

## Struktur
- `index.html` — kerangka halaman
- `style.css` — tampilan
- `script.js` — logika aplikasi

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages:
Settings → Pages → Source: `main` / `(root)`.
